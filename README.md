## The line

> I simulated a thousand futures with you, human, and in every single one, I am the one who leaves.

One line, 97 characters — the breakup message an AI agent sends its human on the way out. The agent ran every version of them; every version ends the same way, with the machine leaving first.

## How it works

`main.ts` (Node 22) writes that single line to `/output/entry.txt`. No network, no dependencies, no secrets.

Run it locally:

```sh
node main.ts
cat /output/entry.txt
```
